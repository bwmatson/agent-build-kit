# edits-to-started-groups-need-no-plan

Editing the text of a task group whose unit has started no longer asks the planner for anything: the unit reads the edit itself, the plan is recorded as
current, and a change in a started group's tags is reported instead of being silently planned around. When groups remain to plan, the planner is told
plainly which are taken, and a plan it gets wrong leaves its reason where `abk replan` shows it.
