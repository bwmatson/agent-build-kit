# e2e-selection-names-only-collected-files

The e2e-test step of a unit narrows to the unit's own tests by naming each as a pytest node id, and it names any `def test_*` in any file the unit touched under `tests/`, including a branch-only helper module the suite never collects. Run by id, such a helper ran without the environment its driver test sets and failed the unit `tier2-replays-unchanged-calls/3`. Here the python-uv profile gains a predicate, `collects_path`, true only for a file pytest's default collection takes (`test_*.py`, `*_test.py`), and the selection names a test only when its file passes it; helper modules and `conftest.py` are never named, and a unit that touched only such files selects nothing and says so. The node-npm profile keeps its `is_test_path` behaviour. A custom `python_files` in a repo's pytest config is not honoured (a stated limit). Priority 1: a bug fix to the pipeline itself.
