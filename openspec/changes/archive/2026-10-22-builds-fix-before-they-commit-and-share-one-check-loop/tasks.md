## 1. [agent-build-kit] [unit-test] A profile declares how its fixers are applied, and the runner applies them to the unit's own files

Priority: 0

Done when `ToolchainProfile` declares an optional `fix_command(files)` that python-uv and node-npm implement (python-uv: the pre-commit hooks over the files; node-npm: `npx oxfmt` then `npx oxlint --fix` over the source files, never `tsc`), a profile without it gets no fixer pass, `repos.<name>.tests.fix_command` replaces the command (`[]` turns it off, unset follows the profile), and the runner's `run_fixers` passes only the unit's modified, added, renamed and untracked files (less locks and artifacts), per project in the project's directory, never a protected file (restoring one a pass changed), ignores the exit status, makes at most two passes, logs a failure to run without stopping, and returns what it changed, skipped and could not run.
