## 1. [agent-build-kit] [unit-test] A profile names the commands an agent may run, a repo can replace them, and each must match the build allow-list

Done when `config.AgentCommand` exists, `python-uv` and `node-npm` provide values, `repos.<name>.agent_commands` replaces them, the Bash-pattern matcher lives in a module that needs no protocol library, an `agent_commands` list outside the build allow-list is refused at config load, and `abk doctor` reports each repo's effective list. It builds only on code already in the main branch and depends on no unbuilt unit; where other changes touch the same lines a rebase resolves it. Estimate: about 340 changed lines.

- [x] 1.1 Test: `tests/test_tool_patterns.py` asserts `allows("Bash(uv run *)", "uv run pytest -q")` is true; `uv run pytest -q; echo $?`, `uv run pytest | tee x`, `python -m pytest tests -q` and `ruff check .` are false; a bare `Bash` entry allows any single command; the module imports with `acp` blocked (`sys.modules["acp"] = None`) in a subprocess; and `runtimes.acp.allows` is the same function object.
- [x] 1.2 Test: `tests/config/test_agent_command_model.py` asserts a string command is split into argv, `{path}` is required when the scope is `file` or `node-id` and refused when it is `whole`, an unknown purpose, scope or extra key is refused, and the model is frozen.
- [x] 1.3 Test: `tests/profiles/test_agent_commands_builtin.py` walks every registered profile and asserts each command it provides matches the allow-list `wiring.allowed_tools(profile, forge, [])` composes; that `python-uv` gives test and check at whole and file scope (`uv run pytest -q`, `uv run pre-commit run --all-files`) and `node-npm` gives test, lint, format and check; and that a profile without the optional attribute gives none.
- [x] 1.4 Test: `tests/config/test_agent_commands_config.py` asserts `agent_commands` is `None` by default and `abk config --show` prints `agent_commands: null`; a list replaces the profile's commands in the effective list and `[]` means none; the effective list of a repo with projects is the repo profile's followed by each project profile's, each once; `python -m pytest tests -q`, `ruff check .` and `uv run pytest -q; echo $?` are each refused at load with a `ConfigError` naming the repo, the index, the line and the allow-list; `uv run pytest -q` loads; the allow-list is the one the build is started with for a repo with a second project profile.
- [x] 1.5 Test: `tests/pipeline/test_agent_commands_no_ecosystem.py` asserts the source of `pipeline/agent_commands.py` contains none of the registered profile names or the words `pytest`, `vitest`, `uv`, `npx`, `npm`, `pre-commit`.
- [x] 1.6 Test: `tests/cli/test_doctor_agent_commands.py` asserts doctor prints an ok line per repo with the number of commands; an info line for a repo whose profile gives none and with no override; a FAIL for a profile registered (with `profiles.registered`) with a command outside its `allowed_tools`, naming the profile, the command and a fix (allow it in the profile, or set `repos.<name>.agent_commands`); and a warn when the commands would not all fit the prompt section's bound.
- [x] 1.7 Move the matcher (`SHELL_OPERATORS`, `_tokens`, `_name_of`, `_command_patterns`, `_matches`, `allows`) from `runtimes/acp.py` to `src/agent_build_kit/tool_patterns.py` and import it back in `acp.py`.
- [x] 1.8 Add `AgentCommand` with its two `StrEnum`s and `RepoConfig.agent_commands` to `config.py`; add `profiles.base.AgentCommands` (optional protocol); add the values to `profiles/python_uv.py` and `profiles/node_npm.py`.
- [x] 1.9 Add `pipeline/agent_commands.py` with `effective(repo)` and `refused(repo)`, the load check `_check_agent_commands` called after `_check_infra` in `config.load`, and `_agent_commands` in `cli/doctor.py` run after `_toolchain`.
