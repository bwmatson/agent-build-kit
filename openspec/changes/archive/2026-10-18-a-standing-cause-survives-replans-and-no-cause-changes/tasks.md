## 1. [agent-build-kit] [unit-test] A standing cause survives a replan, a promotion, a vanished change and a join, a backoff keeps its start, and a cause change closes the gate in the same write

Done when `KEEP` is accepted as a cause by `set_state`, `_record_state` and `_with_state`, resolves to the unit's current cause when it is standing and to none when it is an event cause or absent, carries the previous note unless one is passed and marks the entry `carried`, `upsert` (demotion and promotion), `unplan_vanished` and `join` pass it, the default stays no cause, `STANDING_CAUSES` and `EVENT_CAUSES` partition `Cause`, `StoredUnit.cause_since` returns the time of the entry that set the cause, `backoff_ends` reads it so a carried entry does not restart a backoff while a second parking does, a carry neither counts as a parking nor drops the step, `_record_state` clears `gated_requeue` in the same write when the resolved cause is not `gated`, `release_gated` rewrites the cause in one write on its non-delivered path, and a carried entry written during planning readmits nothing and logs a skip once. It builds only on code already in the main branch and depends on no unbuilt unit; where other changes touch the same lines a rebase resolves it. Estimate: about 320 changed lines.
