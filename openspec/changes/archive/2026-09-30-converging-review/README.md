# converging-review

Give the review loop the outcomes it is missing, so a unit converges instead of
running out of rounds: a reviewer that knows its budget and what exhausting it
costs, a way to defer a non-blocking finding to a follow-up instead of blocking
on it, an escalation for a class of problem that cannot be enumerated, and a
last round that hands work to a person rather than discarding it.

Raising `max_review_rounds` to 5 bought time; it is not the fix, and the limit
should go back to 3 once this lands.
