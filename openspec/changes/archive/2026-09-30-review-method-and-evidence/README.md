# review-method-and-evidence

Give the reviewer a method and an evidence bar, and give its findings a shape
the loop can read. The review prompt says "find everything in one pass" without
saying how; a required change needs no stated consequence; and the verdict is
one block of prose that the next round sees cut off at a character limit.

Borrowed from how a multi-angle code review works — named angles, a concrete
failure scenario per finding, a check of each candidate before it is reported,
ranked and capped output — without the part that multiplies cost: no subagents,
no second reviewer, still one read-only pass per round.
