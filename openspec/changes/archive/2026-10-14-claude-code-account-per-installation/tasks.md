# Tasks

Acceptance: none — the account is a setting, an environment handed to a child process, a path a reader opens, a line a command prints and a record a file keeps, and each is proved by a tier-1 test over a fake `claude`, temporary directories and files, an in-process settings object and the command run in process; no consumer drives a surface this change builds beyond what those tests drive.

Priority: 1
